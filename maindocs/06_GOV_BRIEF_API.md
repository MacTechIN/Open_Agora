# 06. 대정부 브리프 및 연구자 오픈 API

## 1. 대정부 합의 브리프

### 1.1 발행 조건

아래를 **모두** 만족하는 안건에 대해 매월 1일 자동 생성됩니다.

| 조건 | 기준 |
|-|-|
| 누적 토론 카드 | 1,000건 이상 |
| 참여 시민 | 500명 이상 (검증 DID 기준) |
| 이념 군집 | 2개 이상 형성 |
| 합의 카드 | 2차 관문 통과 카드 1건 이상 |

2차 관문은 **모든 군집에서 찬성률 ≥ 0.65이며 군집 간 격차 ≤ 5%p**입니다(→ `03_ALGORITHMS_AI.md` §2.2).

발행 전 생성된 초안은 7일간 플랫폼에 공개되어 이의신청을 받습니다. 시민이 만든 문서가 시민 모르게 국가기관으로 나가서는 안 됩니다.

### 1.2 문서 양식

```markdown
# [정책 권고서] 제2026-04호: 탄력 근로제 및 지역 보조금 개선안

* 발신: CivicAgora 시민 공론장 거버넌스
* 수신: 대한민국 고용노동부 장관 / 국회 환경노동위원회
* 발행일: 2026-04-01

## 1. 공론장 개요
* 총 참여 시민: 12,480명 (ZK-Email 검증 DID)
* 누적 토론 카드: 3,214건 / 댓글: 8,902건
* 온체인 앵커링 머클 해시: 0x9f4a...e12d
* 검증 방법: https://civicagora.org/verify/0x9f4a...e12d
* 집단지성 수렴도: 72.4%

## 2. 진영 초월 핵심 합의 사항
1. 현행 제도의 일률적 적용이 소상공인에게 과도한 행정 비용을 유발한다는 점에
   **88%** 합의 (군집 A 86% / 군집 B 90%)
2. 직종별 유연성 부여 시 노동자의 휴식권 보장 안전장치가 선행되어야 한다는 점에
   **79%** 합의 (군집 A 82% / 군집 B 76%)

## 3. 커뮤니티 도출 최우수 보완책
* 제안 ID: Proposal_772A
* 지지도: 84.1% (군집 간 격차 3.2%p)
* 브리징 점수 b_i: 0.91
* 골자: 업종별 가이드라인 차등화 및 바우처 기반 현장 감독 시스템 도입
* 원문 검증: ceramic://k2t6wz...

## 4. 주요 쟁점 (합의 미도달)
* 적용 사업장 규모 기준: 군집 A 34% / 군집 B 71% — 격차 37%p
* 합의에 이르지 못한 지점을 숨기지 않고 함께 보고한다

## 5. 방법론 고지
* 브리징 행렬 분해 v1.0.0 / 입력 스냅샷 0x9f4a...e12d / 시드 20260921
* 누구나 동일 스냅샷으로 재계산하여 본 수치를 검증할 수 있습니다
```

### 1.3 4절과 5절이 필수인 이유

합의 사항만 골라 보내면 이 문서는 선전물이 됩니다. **합의에 이르지 못한 쟁점과 그 격차를 함께 보고**해야 수신 기관이 여론 지형을 정확히 파악할 수 있고, 플랫폼이 특정 결론을 밀어붙이지 않는다는 신뢰를 얻습니다. 방법론 고지 역시 수치를 독립 검증할 수 있게 하는 필수 항목입니다.

### 1.4 발송

* 국회 의안정보시스템 및 부처 민원 접수 표준 양식으로 변환해 내보냅니다.
* 동일 문서를 플랫폼에 영구 공개하고 온체인에 앵커링합니다.
* 수신 기관의 회신이 있으면 해당 안건 페이지에 함께 게시합니다.

## 2. 연구자용 오픈 데이터 API

"열린 정치 데이터를 정치 연구에 쓰이게 한다"는 원본 목표를 구현하되, 프라이버시 불변식을 지킵니다.

### 2.1 엔드포인트

```
GET /api/v1/research/opinions/export
```

| 파라미터 | 타입 | 필수 | 설명 |
|-|-|-|-|
| `policy_id` | string | ✅ | 안건 고유 식별자 |
| `format` | enum | ⬜ | `json` \| `parquet` \| `csv` (기본 `json`) |
| `since` | date | ⬜ | 해당 일자 이후 데이터만 |

인증 없이 공개하되 IP 단위 요율 제한을 둡니다. 대용량은 Parquet 사전 생성 파일을 CDN으로 제공합니다.

### 2.2 응답

```json
{
  "policy_id": "pol_2026_089",
  "generated_at": "2026-09-21T13:00:00Z",
  "snapshot_root": "0x9f4a...e12d",
  "methodology": { "job": "bridging_mf", "version": "1.0.0", "seed": 20260921 },
  "participant_count": 12480,
  "cluster_count": 2,
  "data": [
    {
      "opinion_id": "op_9812",
      "stance": "ALTERNATIVE",
      "bridging_score": 0.824,
      "opinion_bias_factor": -0.03,
      "cluster_approval": { "cluster_0": 0.86, "cluster_1": 0.83 },
      "reactions": {
        "logical": 142,
        "empathy": 98,
        "needs_factcheck": 4,
        "disagree": 12
      },
      "ai_toxicity_score": 0.04,
      "was_revision_rejected": false,
      "is_adopted_in_brief": true,
      "created_at": "2026-03-14T09:00:00Z"
    }
  ]
}
```

### 2.3 기존 명세에서 제거된 필드

기존 문서의 `user_latent_factor: -0.12`는 **삭제되었습니다**(→ D7).

이 필드는 의견마다 작성자 개인의 잠재 정치 성향을 그대로 노출합니다. 원본 요구인 "정치적 성향은 절대 노출되어서는 안 된다"와 정면으로 충돌하며, 여러 안건의 데이터를 결합하면 특정 개인의 성향 좌표를 복원할 수 있습니다.

대신 **카드 단위 편향값 `opinion_bias_factor`($f_i$)** 를 제공합니다. 이것은 "이 글이 어느 진영에 어필하는가"를 나타내는 값으로, 브리징 연구에 필요한 정보를 그대로 담으면서 개인을 식별하지 않습니다.

### 2.4 익명화 규칙

| 규칙 | 내용 |
|-|-|
| **작성자 미포함** | DID·필명 어느 것도 내보내지 않습니다. 작성자별 글 묶음 복원 불가 |
| **최소 인원** | 참여자 50명 미만 안건은 내보내지 않습니다 |
| **군집 최소 인원** | 20명 미만 군집의 찬성률은 `null` 처리합니다 |
| **시간 정밀도** | 시간 단위로 반올림합니다 (분·초 제거) |
| **본문 제외** | 기본 응답에 본문이 없습니다. 본문은 별도 코퍼스 엔드포인트에서 제공 |
| **블라인드 표시** | 검색 제외 처리된 카드는 `is_restricted: true`로 표시하되 본문은 제공하지 않습니다 |

### 2.5 본문 코퍼스

자연어 처리 연구를 위한 별도 엔드포인트입니다.

```
GET /api/v1/research/corpus
```

토론 카드와 댓글의 본문을 제공하되, 작성자 식별자와 반응 데이터를 결합하지 않습니다. 본문과 성향 데이터를 분리해 제공함으로써 문체 기반 재식별 위험을 낮춥니다.

### 2.6 라이선스

* 데이터: **CC BY 4.0**. 출처 표시 시 상업적 이용을 포함해 자유롭게 사용할 수 있습니다.
* 재식별 시도 금지를 이용 약관에 명시합니다.
* API 응답에 `snapshot_root`를 포함해, 연구자가 인용한 데이터가 온체인 앵커와 일치함을 제3자가 확인할 수 있게 합니다. 재현 가능한 정치학 연구의 전제 조건입니다.

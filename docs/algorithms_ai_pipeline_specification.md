## 1\. 브리징 평가 알고리즘 (Bridging Matrix Factorization)

X(구 Twitter)의 Community Notes 알고리즘을 기반으로, 특정 정당 지지자들만의 몰표를 방어하고 **상반된 정치 성향을 가진 유저들 모두에게 긍정 평가를 받은 글**에 높은 가중치를 부여합니다.

### 1.1 평점 예측 모델 수식

사용자 $u$가 작성글 $i$에 대해 부여한 평점 $r\_{u,i} \\in {0, 1}$ (0: 반대/비공감, 1: 추천/공감)을 다음과 같이 분해합니다:

$$\\hat{r}\_{u,i} = \\mu + b\_u + b\_i + f\_u \\cdot f\_i$$

* $\\mu$: 플랫폼 전체의 평균 평점
* $b\_u$: 사용자 $u$의 관대함 지수 (항상 추천을 주는 유저인지 여부)
* $b\_i$: **게시글 $i$의 고유 품질 및 브리징 지수 (Core Bridging Score)**
* $f\_u \\in \\mathbb{R}^d$: 사용자 $u$의 정치적·이념적 잠재 성향 벡터 ($d=1$일 경우 좌/우 파벌 축)
* $f\_i \\in \\mathbb{R}^d$: 게시글 $i$가 지닌 정치적 편향성 벡터

### 1.2 목적 함수 및 손실 최소화

정규화(L2 Regularization)를 포함한 손실 함수:

$$\\mathcal{L} = \\sum\_{(u,i) \\in \\mathcal{O}} \\left( r\_{u,i} - \\hat{r}\_{u,i} \\right)^2 + \\lambda \\left( b\_u^2 + b\_i^2 + |f\_u|\_2^2 + |f\_i|\_2^2 \\right)$$

* **정치적 양극화 필터링 원리:**

  * 특정 진영 회원들이 좌표를 찍고 대량으로 추천을 누를 경우, 해당 그룹의 $f\_u$와 글의 $f\_i$ 방향이 일치하여 내적 $f\_u \\cdot f\_i$ 값이 커집니다.
  * 따라서 잔여 오차를 줄이는 과정에서 **고유 브리징 품질 $b\_i$는 상승하지 않습니다**.
  * 반대로 $f\_u$ 부호가 반대인 집단(상대 정당 지지자)이 추천을 눌러주어야만 $b\_i$가 큰 양수 값을 갖게 되어 리더보드 최상단에 노출됩니다.

## 2\. Pol.is 기반 실시간 합의 도출 (PCA \& Clustering)

수천 명의 유권자가 참여한 투표 매트릭스를 2차원 공간으로 차원 축소하여 여론 지형도를 시각화합니다.

```
  진영 A (우려 중심)                     진영 B (원안 지지)
      \\\[ Cluster 1 ]                          \\\[ Cluster 2 ]
            \\\\                                      /
             \\\\                                    /
              ───► \\\[ Common Ground : 제3의 대안 ] ◄───
                   (양 진영 60% 이상 합의 지대)
```

1. **희소 행렬 입력:** 유저-의견 간 동의/비동의 행렬 $M\_{m \\times n}$.
2. **주성분 분석 (PCA):** 제1, 제2 주성분 축을 도출하여 2차원 좌표로 투영.
3. **K-평균 군집화:** 이념적 대립을 이루는 두 개 이상의 대표 군집 추출.
4. **합의 대안(Common Ground) 자동 추출:**
$$\\text{Consensus}(i) = \\min\_{k \\in \\text{Clusters}} \\left( \\frac{\\sum\_{u \\in C\_k} \\mathbb{I}(r\_{u,i} = 1)}{|C\_k|} \\right) \\ge 0.60$$
모든 군집에서 각각 60% 이상의 찬성률을 기록한 '수정·대안' 의견을 메인 합의 배너로 승격합니다.

## 3\. 실시간 한국어 AI 톤 코칭 \& 중재 엔진

사용자를 일방적으로 처벌하는 것이 아니라, 글 작성 과정에서 건설적인 정책 토론 문장으로 유도합니다.

### 3.1 3단계 인퍼런스 파이프라인

```
\\\[User Input] 
     │
     ▼
\\\[Step 1: 유해성 초고속 스크리닝 (KcELECTRA-base)]
     ├─ 지연시간: < 30ms
     └─ 결과: 비속어, 은어, 멸칭 탐지
     │
     ▼
\\\[Step 2: 10대 편향/악플 정밀 분류 (Smilegate KorUnsmile)]
     ├─ 라벨: 악플, 지역차별, 연령비하, 젠더혐오 등 Multi-label
     └─ Toxicity Score > 0.65 발생 시 인라인 배너 트리거
     │
     ▼
\\\[Step 3: 온디바이스/경량 LLM 순화문 생성 (EEVE-Korean-10.8B)]
     └─ 작성자의 정책 비판 논점은 유지하면서 정중한 논거 표현으로 원클릭 변환
```

### 3.2 AI 시스템 프롬프트 (Style Transfer Engine)

```jinja
System: 당신은 대한민국 국회 입법조사관 수준의 어휘를 구사하는 중립적 정책 코치입니다.
User: 아래 사용자가 작성한 문장에서 감정적 비난, 냉소, 인신공격을 제거하고 팩트 중심의 정중한 반박문으로 재작성하십시오.

규칙:
1. 작성자의 본래 주장과 비판 취지는 100% 보존할 것.
2. 정책적 사실관계와 논거 위주로 문맥을 다듬을 것.
3. 500자 이내 구조화 포맷에 맞출 것.

\\\[원문]
"{raw\\\_user\\\_text}"

\\\[출력 포맷 (JSON)]
{
  "toxicity\\\_score": 0.82,
  "detected\\\_violations": \\\["비아냥/조롱", "인신공격"],
  "suggested\\\_revision": "해당 지원금 정책은 예산 추계의 구체성이 부족하여 중장기적 재정 건전성을 악화시킬 위험이 있습니다."
}
```

# 04. 평판 시스템 및 중재 정책

## 1. 평판 점수

### 1.1 획득

| 행위 | 점수 | 비고 |
|-|-|-|
| 구조화된 토론 카드 작성 | **+10** | 1일 최대 5건까지만 가점 |
| 반대 성향 사용자로부터 💡·🤝 획득 | **+5** / 건 | **일 1회 배치 정산** (INV-4) |
| 같은 성향 사용자로부터 💡·🤝 획득 | **+1** / 건 | 몰표 가치를 의도적으로 낮게 설계 |
| 작성 카드가 합의 배너로 승격 | **+50** | 안건당 1회 |
| 작성 카드가 대정부 브리프에 수록 | **+100** | 최상위 기여 |
| 안건 등록 후 카드 20건 이상 유치 | **+20** | 빈 안건 남발 방지를 위한 조건부 |

### 1.2 차감

| 행위 | 점수 | 추가 제재 |
|-|-|-|
| 톤 코칭 순화 권고를 거부하고 게시 | **-30** / 회 | 해당 글 디랭킹 |
| 악의적 비방 댓글 작성 확인 | **-50** | **7일간 작성 정지** |
| 블라인드 처리 누적 3회 | **-100** | 30일간 작성 정지 |
| 허위 출처 링크 게시 확인 | **-40** | 해당 카드 "미검증 출처" 영구 표시 |

### 1.3 설계 근거

**교차 진영 가점(+5)이 동일 진영 가점(+1)의 5배인 것이 이 시스템의 핵심입니다.** 평판을 올리는 가장 빠른 길이 "내 편을 결집시키는 글"이 아니라 "반대편도 수긍하는 글"이 되도록 보상 구조 자체를 설계했습니다. 이 비율을 바꾸면 플랫폼의 성격이 근본적으로 달라지므로, 조정 시 반드시 영향 분석이 필요합니다.

카드 작성 가점에 일일 상한(5건)을 둔 이유는 양으로 점수를 쌓는 경로를 막기 위해서입니다. 상한을 넘겨도 글은 쓸 수 있고 반응 가점도 받습니다. 기본 가점만 붙지 않습니다.

### 1.4 산출과 공개

* 점수는 파생값이며 일 1회(KST 04:00) 브리징 재학습 직후 전량 재계산합니다.
* 회원 랭킹은 1위부터 전체 순위를 공개합니다. 본인·타인 모두 점수와 등수를 검색할 수 있습니다.
* 랭킹에 노출되는 정보는 **필명, 점수, 등수, 배지, 가입 연도**뿐입니다. 정치 성향·정당 정보는 어떤 경로로도 노출되지 않습니다(INV-1).
* 점수 변동 내역은 본인에게만, 그것도 항목별 합계로만 표시합니다. 개별 반응자를 특정할 수 있는 형태로는 제공하지 않습니다(INV-4).

## 2. 배지 (Soulbound Token)

평판 점수는 매일 변하므로 온체인에 올리지 않습니다. 대신 **되돌릴 수 없는 마일스톤만** 양도 불가 토큰(SBT)으로 발행합니다.

| 배지 | 조건 |
|-|-|
| 🏛️ 검증 시민 | ZK-Email 인증 완료 (가입 시 자동) |
| 🌉 브리지 빌더 | 교차 진영 긍정 반응 누적 100건 |
| 📜 입안자 | 대정부 브리프에 카드 수록 |
| 🔬 팩트 파인더 | 허위 출처 신고가 3회 이상 확인 |
| ⚖️ 합의 설계자 | 합의 배너 승격 카드 3건 이상 |

배지는 회수되지 않습니다. 제재를 받아도 과거의 기여는 남습니다. 반대로 배지가 현재의 평판을 보증하지도 않으므로, 프로필에는 배지와 현재 점수를 함께 표시합니다.

## 3. 삭제 없는 중재

**CivicAgora에는 글 삭제 기능이 없습니다.** 작성자 본인도 삭제할 수 없습니다(→ D3). 대응은 노출 조정 3단계뿐입니다.

| 단계 | 조건 | 처리 | 결정 주체 |
|-|-|-|-|
| **1. 디랭킹** | 순화 권고 거부 게시 | 정렬 순위 하락. 내용은 그대로 보임 | 자동 |
| **2. 블라인드** | 신고 누적 + AI 유해성 재확인 | 본문 가림. "가려진 글 보기" 클릭 시 표시 | 자동 + 이의신청 |
| **3. 검색 제외** | 명백한 불법·음란·중대 명예훼손 | 검색·목록에서 제외. 직접 링크로는 열람 가능 | 시민 배심 |

### 3.1 원문은 어느 단계에서도 제거되지 않는다

블라인드는 **UI 계층의 표시 규칙일 뿐**입니다. IPFS의 원문 블록도, 온체인 머클 앵커도 그대로 유지되며, 독립 노드 운영자는 언제나 원문을 검증할 수 있습니다. 이것이 "누구도 데이터를 왜곡하거나 지울 수 없다"는 원칙을 지키면서 유해 콘텐츠 노출은 막는 방식입니다.

### 3.2 중재 자체를 감시 가능하게 만든다

노출 조정은 그 자체로 검열 권력입니다. 따라서 모든 처리 이력을 **공개 로그**로 남깁니다.

```json
{
  "target": "ceramic://k2t6wz...",
  "action": "BLIND",
  "reason": "HATE_SPEECH",
  "toxicity_score": 0.91,
  "model_version": "kor_unsmile-1.2.0",
  "report_count": 14,
  "decided_at": "2026-09-21T11:00:00+09:00",
  "jury_id": null,
  "appeal_status": "OPEN"
}
```

누구나 이 로그를 감사해 특정 성향의 글만 선별적으로 가려지는지 통계적으로 검증할 수 있습니다. 진영별 블라인드 비율은 월간 투명성 보고서로 공개합니다.

### 3.3 시민 배심

3단계(검색 제외)는 자동 판정에 맡기지 않습니다.

* 평판 상위 사용자 중 무작위 추첨으로 **7인 배심**을 구성합니다.
* 배심원의 잠재 성향 `f_u`가 한쪽으로 쏠리지 않도록, 좌·우·중도에서 균형을 맞춰 추첨합니다.
* 5인 이상 찬성 시 검색 제외가 확정됩니다.
* 배심원 구성과 투표 결과는 집계로만 공개하고 개별 배심원은 익명입니다.

### 3.4 이의신청

모든 단계에 이의신청이 가능하며, 인용되면 차감된 점수가 복원되고 제재 이력이 말소됩니다. 이의신청 처리 통계 역시 투명성 보고서에 포함합니다.

## 4. 제재 시 유의점

작성 정지 기간에도 다음은 유지됩니다.

* 읽기와 검색은 제한 없습니다.
* 기존 글은 그대로 노출됩니다. 제재는 사람이 아니라 행위에 대한 것입니다.
* 반응(💡🤝🔍⚖️)은 계속 남길 수 있습니다. 제재자를 브리징 표본에서 배제하면 오히려 특정 성향의 표본이 편중되기 때문입니다.
